
# Walmart Store Sales

## Project Summary

The project analyzes Walmart store sales data to evaluate performance trends and inform business strategies.

---

## Business Problem

Assessing sales performance post-recession to identify key factors affecting revenue.

---

## Objective

- Analyze sales trends
- Identify key metrics
- Generate actionable insights

- Create visualizations
- Analyze insights
- Present results
