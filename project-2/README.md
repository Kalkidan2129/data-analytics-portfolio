
# Walmart Store Sales

![Project Preview](./screenshots/preview.png)

## Project Summary

The project developed a Power BI dashboard that analyzes year‑over‑year sales across 45 randomly selected Walmart stores in the United States from February 2010 to October 2012, a period emerging from the 2008 recession. It provides a visual view of sales trends, enabling comparison of performance over time and across locations.

---

## Business Problem

Walmart stores experienced sales pressure similar to other discount and department retailers during the early recovery from the 2008 financial crisis. Understanding the factors driving these sales fluctuations is essential for improving store performance and guiding strategic decisions.

---

## Objective

- Import and load the Walmart sales CSV data into Power BI Desktop
- Create a calendar table and establish relationships to enable time‑intelligence calculations
- Develop DAX measures for total sales, month‑over‑month and year‑over‑year growth

---

## Project Workflow

- Import the Walmart sales CSV file into Power BI Desktop
- Create a calendar table and refresh the date table for time‑intelligence
- Define relationships between the Walmart and Calendar tables
- Build DAX measures for sales metrics and format them appropriately
- Deploy the completed dashboard to Power BI Cloud and add branding elements

---

## Key Insights

- Sales showed clear seasonal patterns, with certain months recording higher weekly sales across stores
- Year‑over‑year growth varied among the 45 stores, indicating differing recovery rates
- Holiday weeks and periods of higher unemployment were associated with lower sales figures
- Time‑intelligence measures enabled accurate month‑over‑month and year‑over‑year comparisons
