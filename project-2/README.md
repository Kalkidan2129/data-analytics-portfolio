
# Walmart Store Sales

## Project Summary

This project involved creating a Power BI dashboard to analyze year-over-year sales performance of 45 Walmart stores in the US during the post-Great Recession period from February 2010 to October 2012. The dashboard aimed to provide insights into sales trends and the impact of economic factors on retail performance during this challenging economic transition.

---

## Business Problem

Walmart stores faced sales challenges during the post-recession recovery period, requiring data-driven insights to understand performance trends and external factors affecting sales. The business needed a comprehensive analytics solution to track sales performance across multiple stores and identify patterns that could inform strategic decisions.

---

## Objective

- Analyze year-over-year sales performance across 45 Walmart stores
- Identify the impact of economic factors like unemployment and holidays on sales
- Create an interactive dashboard for visualizing sales trends and metrics

---

## Tools & Technologies

- Power BI Desktop
- Power BI Cloud
- Excel
- DAX (Data Analysis Expressions)
- CSV data processing

---

## Project Workflow

- Import and preprocess Walmart sales data from CSV files
- Create calendar and date tables for time-based analysis
- Establish relationships between data tables
- Develop conditional columns and DAX measures for key metrics
- Design and deploy an interactive dashboard with visualizations

---

## Key Insights

- Sales performance varied significantly across different time periods during the post-recession recovery
- Economic factors like unemployment rates had measurable impacts on weekly sales
- Holiday periods showed distinct sales patterns compared to regular weeks
- Year-over-year comparisons revealed trends in recovery and growth patterns
