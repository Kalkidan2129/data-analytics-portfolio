
# Revenue Forecasting and Performance Analysis of Vodafone Qatar (2021–2023)

![Project Preview](./screenshots/preview.png)

## Project Summary

A comprehensive data analytics project transforming raw Vodafone Qatar telecom data (2021–2023) into actionable business intelligence. The project establishes a unified, ML-ready data foundation to enable precise revenue forecasting, performance tracking, and strategic decision-making for finance and strategy teams.

---

## Business Problem

Telecom revenue varies significantly across regions and segments, but a lack of consolidated visibility makes it difficult to identify growth areas and revenue risks. Fluctuations in churn and subscriber behavior create uncertainty in budget planning and forecasting.

---

## Objective

- Improve quarterly revenue forecasting accuracy to optimize investment across high-growth segments.
- Lower churn in key telecom segments to protect recurring revenue.
- Create a unified view of revenue, subscribers, churn, and network performance for data-driven decision-making.

---

## Tools & Technologies

- Python
- Pandas
- Microsoft Fabric
- Power BI
- NexusMax
- Numtra
- Machine Learning (Regression)

---

## Project Workflow

- Clean and standardize raw telecom data to resolve missing values and formatting issues.
- Engineer a centralized Date table to enable reliable time-based KPI analysis.
- Transform and enrich datasets using NexusMax and Microsoft Fabric for ML-readiness.
- Apply supervised regression techniques to model historical trends for quarterly revenue forecasting.
- Develop a comprehensive performance dashboard visualizing ARPU, churn, and network availability.

---

## Key Insights

- Total revenue increased 14% QoQ to $108K, with Doha contributing the largest share via 72M subscribers.
- Churn for high-value mobile prepaid customers is above 2.5%, increasing by 0.3% QoQ.
- Mobile Postpaid and Fixed Broadband churn rates (2.41%–2.74%) exceed the overall churn rate of 2.51%.
- Network availability is maintained at a high score of 99.95%, providing a strong foundation for customer retention.
